# Forge Agent Tools
Free client-side tools for people running AI agents (Claude Code, Codex, Hermes, n8n). Static HTML/CSS/JS, no build, no trackers, no CDNs.

- `index.html` – home
- `tools/cost-calculator.html` + `tools/calc.js` – Agent Cron Cost Calculator
- `test/calc.test.js` – run `node test/calc.test.js`

Deploy: push to a GitHub repo, enable Pages (branch root). `.nojekyll` is included.
The `#pack` link is a placeholder for the Agent-Ops-Pack (Gumroad URL TBD).
